# CS2 CRAFT

Русскоязычный сайт про скины и утилиты CS2: калькулятор крафтов (оружие и ножи), каталог всех скинов с историей цен, стикер-крафты, паттерны, раскидки профи с 3D-повтором, коллауты, профили игроков, генератор прицела и утилиты.

**Сайт:** https://vsemvamdam.github.io/cs2-craft/

## Что внутри

| Раздел | Что умеет |
|---|---|
| **Крафты** (`#/tradeup`) | Контракты 10 → 1 и 5 тайных → нож/перчатки. Шансы, флоат результата (нормированная формула), EV после комиссии Steam/Skinport, ROI, шанс профита, безубыточная цена входа, симуляция 1000 контрактов, пороги флоата для «Прямо с завода», ссылка на контракт. Учитывает правила на ноябрь 2026: StatTrak™, сувениры (с 21.05.2026), перчаточные кейсы, фазы Doppler. |
| **Скины** (`#/skins`, `#/skin/<id>`) | Все ~2000 скинов оружия, ножей и перчаток. Фильтры, сортировка по цене. Страница скина в стиле wiki.cs.money: износ со стрелками, ввод флоата и шкала FN–BS с диапазоном скина, паттерны, цены по износам (обычный/StatTrak™/сувенир), график цены за всю историю, «скрафтить этот скин». |
| **Стикер-крафт** (`#/craft`) | До 5 наклеек в любом месте, поворот, потёртость, брелок, стоимость сборки и оценка готового, «Осмотреть в CS2» (masked inspect link), `!gen`, PNG, ссылка, свои сохранённые крафты, случайный крафт. |
| **Паттерны** (`#/patterns`) | Fade %, фазы Doppler/Gamma Doppler, известные сиды Case Hardened и Marble Fade. |
| **Раскидки** (`#/nades`) | Все гранаты из про-демок, сгруппированные в раскидки: точки падения на радаре, позиции, откуда их кидают (пунктиром), фильтры по типу/стороне/игроку/турниру, «Мой набор». Окно раскидки — **3D-повтор прямо на сайте** по настоящей геометрии карты: «Видео» (бросок от первого лица → полёт за гранатой → результат), «Прицел» (Shift), «Позиция» (Ctrl), свободная камера, скачивание видео; клавиши броска (ЛКМ/ПКМ, прыжок, бег), `setpos`/`setang`, список профи — по клику повтор именно его броска из матча. |
| **Коллауты** (`#/callouts`) | Радар каждой карты с зонами и подписями в двух вариантах: английские (как в игре и у профи) и русские (как говорят в комах), плюс мелкие точки внутри зон и источники. Зоны построены по позициям игроков из демок. |
| **Статистика** (`#/stats`, `#/stats/<steamid>`) | Любой профиль Steam по ссылке, SteamID или нику: уровень и XP (прогресс до следующего), игры и часы, топ игр, часы в CS2, пожизненная статистика CS2 (K/D, HS, точность, оружие, карты, последний матч), баны, друзья, инвентарь CS2 с оценкой по ценам сайта, история уровня/часов по дням и место в рейтинге. Рейтинг профилей (уровень, игры, часы, CS2, значки, возраст) с фильтром по стране; данные свежие при каждом открытии, рейтинг обновляется каждые 10 минут. |
| **Игроки** (`#/players`, `#/player/<steamid>`) | Профи из турнирных демок: K/D, ADR, HS, первые дуэли, AWP, урон гранатами, матчи, прицел из демки (с открытием в генераторе), раскидки игрока; вкладка «Команды». |
| **Прицел** (`#/crosshair`) | Генератор прицела: коды нового формата `CS…`, попиксельный предпросмотр в выбранном разрешении (включая растянутое 4:3) на процедурных фонах или своём скриншоте, импорт старых кодов `CSGO-…` и команд консоли, экспорт в команды и `autoexec.cfg`, пресеты, проверенные прицелы профи, ссылка `#/crosshair?c=<код>`. |
| **Утилиты** (`#/tools`) | Перевод сенсы и eDPI, viewmodel, конфиг для тренировки, бинды, параметры запуска. |

## Как обновляются данные

Всё работает на GitHub Pages + GitHub Actions, сервер не нужен.

- **`.github/workflows/site.yml`** — каждые 6 часов и при каждом пуше:
  1. обновляет базу предметов из [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API) (`scripts/build-db.mjs`);
  2. собирает текущие цены — Steam Market (минимальный лот и число лотов), Skinport (минимум, медианы 7/30 дней, фазы Doppler) и курс ЦБ РФ (`scripts/fetch-prices.mjs`);
  3. дописывает ежедневный снимок цены каждого варианта;
  4. собирает сайт и публикует его на Pages.
- **`.github/workflows/history.yml`** — полная история сделок Steam с первой продажи (`scripts/fetch-history.mjs`). Steam отдаёт её только авторизованному аккаунту, поэтому нужен секрет (см. ниже). Каждый запуск работает до 5 часов и продолжает с места остановки; первый полный проход по ~21 000 вариантов занимает 1–2 дня, дальше всё обновляется по кругу.
- Сами данные (цены, снимки, история) лежат не в git, а архивами в релизе **`data-store`** — история репозитория не раздувается.

### Включить полную историю цен Steam

1. Лучше завести/взять **второй** аккаунт Steam (токен даёт доступ к аккаунту).
2. Получить токен на своём компьютере. Windows — в PowerShell (Win+X → «Терминал»), не в окне «Выполнить»:
   ```powershell
   winget install OpenJS.NodeJS.LTS        # один раз; потом закройте и снова откройте терминал
   mkdir $HOME\cs2-login; cd $HOME\cs2-login
   npm init -y; npm install steam-session qrcode-terminal
   curl.exe -L -o steam-login.mjs https://raw.githubusercontent.com/vsemvamdam/cs2-craft/main/scripts/steam-login.mjs
   node steam-login.mjs
   ```
   Отсканируйте QR-код в приложении Steam (значок щита → «Сканировать QR-код»), подтвердите вход — в терминале появится токен. (Если репозиторий склонирован — то же самое делает `npm install && npm run steam-login`.)
3. Скопировать токен в **Settings → Secrets and variables → Actions → New repository secret**, имя `STEAM_REFRESH_TOKEN`. Больше нигде его не храните.
4. **Actions → «История цен Steam» → Run workflow** (или дождаться расписания).

Токен живёт ~200 дней; когда Steam перестанет его принимать, в логе будет «403» — повторите шаг 2–3.

> GitHub отключает расписания в репозиториях без активности 60 дней. Если цены перестали обновляться — зайдите в Actions и включите workflow обратно.

### Статистика Steam и CS2 (сервер профилей)

GitHub Pages не умеет делать запросы к Steam со своим ключом, поэтому для раздела «Статистика» есть маленький сервер на Cloudflare Workers (`worker/`, бесплатный тариф). Его разворачивает **`.github/workflows/worker.yml`**, адрес попадает в `public/data/api.json`.

1. **Ключ Steam Web API:** https://steamcommunity.com/dev/apikey (любой аккаунт, домен `vsemvamdam.github.io`) → секрет `STEAM_API_KEY`.
2. **Cloudflare:** зарегистрироваться на https://dash.cloudflare.com/sign-up, открыть **Workers & Pages** (при первом входе выбрать поддомен `*.workers.dev`), скопировать **Account ID** → секрет `CLOUDFLARE_ACCOUNT_ID`; My Profile → API Tokens → Create Token → шаблон **«Edit Cloudflare Workers»** + право `Account · D1 · Edit` → секрет `CLOUDFLARE_API_TOKEN`.
3. **Actions → «Сервер статистики (Cloudflare Worker)» → Run workflow** (или любой пуш в `worker/`).

Секреты — в Settings → Secrets and variables → Actions. Сервер хранит в базе D1 только публичные данные профилей, которые кто-то открыл на сайте (для рейтинга и графиков).

## Локальная разработка

```bash
npm install
npm run db            # скачать и собрать базу предметов в public/data
npm run dev           # http://localhost:5173/cs2-craft/
npm test              # проверка математики контрактов и inspect-ссылок
```

Без цен сайт тоже работает: в калькуляторе можно вводить цены вручную. Чтобы подтянуть цены локально: `npm run prices && npm run site-data` (нужен доступ к Steam/Skinport).

## Раскидки профи

**`.github/workflows/nades-all.yml`** разбирает весь архив про-демок OpenCS2 порциями по 480 карт в 16 параллельных задачах (следующая порция запускается сама; 4 из 20 мест для задач GitHub остаются сборке сайта). Из каждой демки (`tools/demos/extract_nades.py`, demoparser2) берутся броски с 3D-траекторией, кнопкой и названием места, позиции игроков с названиями мест (для коллаутов) и статистика с прицелами игроков. `tools/demos/build_lineups.py` собирает из этого раскидки, коллауты и профили игроков. Всё лежит в релизе `data-store` (`nades-raw`, `nades-proc`, `nades-site`), сборка сайта подкладывает `nades-site` в `public/data/`.

3D-геометрия карт для повторов — `public/maps3d/*.bin.gz`, собирается `tools/maps3d/build_meshes.py` из коллизионных мешей [awpy-data](https://github.com/pnxenopoulos/awpy-data) (карты © Valve). Русские названия коллаутов — `public/data/callouts/names.json` (с источниками по каждой карте).
